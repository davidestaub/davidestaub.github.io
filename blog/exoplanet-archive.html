Using the filters

Drag around a knob to turn it, click a tick to select a setting, or use the arrow keys when a knob is focused. The illuminated readout shows the selected setting. Filters combine: a planet must match every selection. Temperature uses a consistent zero-albedo, full-redistribution equilibrium estimate from stellar temperature, stellar radius and orbital distance. It is not a measured surface temperature. Size uses physical diameter. Stellar letters are spectral classes; the menu includes O, B, A, F, G, K and M, plus compact-star and brown-dwarf hosts. These are host categories, not a claim that all stars fit into seven types. The catalogue contains 40 planets. Interior structures and landscapes illustrate possibilities. Globe colours, cloud patterns and terrain are not resolved photographs. Missing published spectral types and measured diameters are excluded only when that specific filter is selected. System data were checked against the NASA Exoplanet Archive on 13 September 2026. Published solutions and any derived values are linked in each system view.
